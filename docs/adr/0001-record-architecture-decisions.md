# 1. Record architecture decisions

Date: 2026-11-11 · Status: Accepted

## Context
Mini Bank is a solo learning project that will be picked up after gaps of weeks. Decisions need to survive those gaps.

## Decision
Keep one short Markdown ADR per decision in `docs/adr/` (context, decision, consequences). Superseding an ADR means writing a new one that links back, never editing the old one.

## Consequences
Every PR that changes a decision includes an ADR. The initial list is in build doc section 15.
